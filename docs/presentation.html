TensorCanvas

Explore. Understand. Intervene.

A visual studio that makes the inner workings of neural networks understandable and experimentally accessible — build, train, watch the forward pass, and reach in to change weights, all in the browser.

The idea

Neural networks are usually a black box.

Most tools show you a network's architecture or its final accuracy. TensorCanvas lets you watch it compute and reach in and change it — from a 3-neuron toy to a 62M-parameter pretrained AlexNet, in the same canvas.

① Build → ② Train → ③ Observe → ④ Intervene

Under the hood it's a graph compiler with a drawing UI: the canvas graph becomes a real PyTorch model that we run, train, and inspect.

Build → Train → Observe → Intervene
What it does

Draw it. Train it. See it think.

  • Visual builder — drag nodes, set weights / bias / activations, compile to PyTorch with per-node error checks.
  • Live training — upload data, configure optimizer/loss/scheduler, stream metrics over SSE with checkpoints.
  • Forward-pass replay — watch neurons fire layer by layer with labelled activations + predictions.
  • Live intervention — edit a weight in place, re-run, compare.
  • Real pretrained nets — load AlexNet / VGG-16 and classify any image (top-5 ImageNet).
