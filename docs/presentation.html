TensorCanvas

Explore. Understand. Intervene.

The problem: a neural network is a black box. You get to see its architecture, or its final accuracy — but almost never what actually happens inside it as it computes, and you can't easily reach in and change it.

What we built: a visual studio where you draw a network, compile it to real PyTorch, train it, then watch the forward pass neuron-by-neuron and edit the weights live to see how behaviour changes — all in the browser.

Motivation

The whole AI field is racing to open the black box.

A major research direction right now — mechanistic interpretability — is about looking inside models: finding the concepts they represent internally, and even changing them. The striking result isn't just reading the model, it's surgically editing its internals to steer its behaviour.

🌉 Golden Gate Claude (Anthropic, 2024): researchers located an internal feature inside Claude 3 and simply amplified it — the model became obsessed with the Golden Gate Bridge. "Not a prompt, not fine-tuning — a precise, surgical change to the model's internal activations."
Scaling Monosemanticity — Anthropic, May 2024 · anthropic.com/news/golden-gate-claude
See also: "Language models can explain neurons in language models" — OpenAI, 2023.

These are frontier-lab tools on billion-parameter models. TensorCanvas brings the same idea down to earth: see activations fire layer-by-layer and reach in and edit the weights — on networks a student can build, train, and understand end-to-end.

Why open source

An interpretability tool is worth more shared.

A tool for understanding models is educational by nature — it should be free to use, inspect, reproduce, and extend. So we open-sourced it and made it genuinely extensible (add a layer, dataset, or pretrained model with a documented recipe).

  • License → Apache-2.0. Permissive (anyone can use/modify/extend) and the only mainstream permissive license with an explicit patent grant + retaliation — the right fit for a tool implementing published NN algorithms, and the ML-ecosystem standard (TensorFlow, Keras, JAX, Hugging Face).
  • Why not the others. MIT/BSD are permissive but lack the patent grant; GPL/AGPL are copyleft — hostile to free reuse. Every dependency we use is permissive (MIT/BSD), so there are no license conflicts.
  • Code vs data. Pretrained weights carry ImageNet's non-commercial research/education terms — so we download them at runtime and never redistribute them.
  • Community-ready. Apache LICENSE + NOTICE, Code of Conduct, Contributing guide, Security policy, extension recipes, and a citable CITATION.cff.

What it does

Draw it. Train it. See it think.

  • Visual builder — drag nodes, set weights / bias / activations, compile to PyTorch with per-node error checks.
  • Live training — upload data, configure optimizer/loss/scheduler, stream metrics over SSE with checkpoints.
  • Forward-pass replay — watch neurons fire layer by layer with labelled activations + predictions.
  • Live intervention — edit a weight in place, re-run, compare — the black-box idea, hands-on.
  • Real pretrained nets — load AlexNet / VGG-16 and classify any image (top-5 ImageNet).
