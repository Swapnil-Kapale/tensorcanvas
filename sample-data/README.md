# Sample data

Ready-made data so you can see TensorCanvas work end to end without hunting for a
dataset. Everything here is generated by `generate.py` (three synthetic shape
classes: vertical bar, horizontal bar, diagonal).

## Contents

| File | What it is | Use it for |
|---|---|---|
| `generate.py` | Regenerates everything below | Re-create the data on a fresh machine |
| `example-shapes.csv` | 784-feature (28×28) tabular data, 3 classes | Training the **ANN/MLP** example (dataset upload) |
| `shapes-images.zip` | The same 3 classes as 28×28 grayscale PNGs in class subfolders | Image-ZIP dataset upload / **CNN** training |
| `samples/*.png` | One loose image per class | Observe → **Upload an image** |
| `alexnet.tcnet.json` | The AlexNet architecture as a `.tcnet.json` | Build → **Import** to get the exact shape for pretrained AlexNet |

## Regenerating

`example-shapes.csv` is large (~3.8 MB) and is **git-ignored** (see the repo
`.gitignore`); regenerate it locally when you need it:

```bash
cd sample-data
uv run --project ../server python generate.py
```

(Using the server's environment gives you NumPy + Pillow, which the generator
needs. Alternatively run it in any Python with `numpy` and `pillow` installed.)

## Quick end-to-end

- **ANN:** Build → Load example → *MLP* → Compile → Train → upload
  `example-shapes.csv` → train → Observe.
- **CNN:** Build → Load example → *CNN* (small) → Compile → Train → upload
  `shapes-images.zip` → train → Observe → upload a `samples/*.png`.
- **Pretrained AlexNet:** Build → Import `alexnet.tcnet.json` (or Load example →
  CNN → AlexNet) → Compile → Observe → Load pretrained AlexNet weights → upload
  any photo.
